## Problem

`attavo doctor`'s third proof classes every first-parent commit on the tenant's `main` since the install as recorded, ordinary, or unrecorded, and its JSON entry carries the three counts and the boundary-evasion count (issue #72): the governed-versus-ordinary path ratio the operator screen renders. It carries no lists, so a reader of the ratio cannot see which merges arrived outside an item (a pin, a lane, a signal branch) or which commits lack a record; the only way to name them is to re-run the classification by hand with `git rev-list` against the records, which is the doctor's job.

Retires: the by-hand `git rev-list --first-parent` read of the ordinary merges, and the screen's ratio as a number with nothing behind it.
